# RupalShield

> Anti-theft gadget registry and verification platform for electronics repair hubs and owners.

## Tech Stack
- **Frontend**: Next.js 15 (App Router), TypeScript, Tailwind CSS, Lucide React
- **Design System**: High-contrast monochrome black & white aesthetic
- **Backend / DB**: Supabase (PostgreSQL with Row Level Security, RPCs)
- **Optical Engine**: HTML5 camera stream with `BarcodeDetector` API + 15-digit Luhn (Mod 10) validator

## Key Features
- **The Stealth Safety Protocol**: Deceptive neutral OEM diagnostic UI for stolen devices with zero counter alarm, background GPS/IP telemetry, and Clean Hands Exoneration tokens.
- **Owner Registry**: Cryptographic Digital Ownership Deeds and one-tap "Report Stolen" toggle generating printable Police Clearance Dockets.
- **Public Verification**: Fast IMEI check with simulated anti-scraping rate limits.
